## Features

This calculator supports 10 mathematical operations:

1.  **Addition** --- adds two numbers.
2.  **Subtraction** --- subtracts the second number from the first.
3.  **Multiplication** --- multiplies two numbers.
4.  **Division** --- divides the first number by the second and checks
    for division by zero.
5.  **Modulus** --- returns the remainder after division and checks for
    a zero divisor.
6.  **Factorial** --- calculates the factorial of a non-negative
    integer.
7.  **Power** --- raises a base number to an exponent.
8.  **Percentage** --- calculates a percentage of a total. For example,
    20% of 500 is 100.
9.  **Square root** --- calculates the real square root of a
    non-negative number and handles negative inputs.
10. **Absolute value** --- returns the non-negative magnitude of a
    number.

Option **11** exits the program.

## How to Run

### Using Python IDLE

1.  Save the Python code in a file named `calculator.py`.
2.  Open `calculator.py` in Python IDLE.
3.  Select **Run → Run Module**, or press **F5**.
4.  Choose an operation from the menu and follow the prompts.

### Using a terminal or command prompt

1.  Open a terminal in the folder containing `calculator.py`.

2.  Run:

    ``` bash
    python calculator.py
    ```

    On Windows, if the `python` command is not available, try:

    ``` bash
    py calculator.py
    ```
